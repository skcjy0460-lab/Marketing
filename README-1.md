## 📊 블로그 지수 산정 기준

| 항목 | 가중치 | 만점 기준 |
|------|--------|-----------|
| 콘텐츠 풍부도 | 45% | 글자수 2,000자 이상 |
| 이미지 활용도 | 35% | 이미지 8장 이상 |
| 링크/태그 활용 | 20% | 링크+태그 조합 |

### 등급 기준
- **S등급** (85점~): 최상위 노출 가능
- **A등급** (70~84점): 상위 노출 양호
- **B등급** (55~69점): 중위권, 개선 필요
- **C등급** (40~54점): 하위권, 전략 수정 필요
- **D등급** (~39점): 즉시 개선 필요

`app.py` 내 다음 부분을 Toss Payments 또는 카카오페이 API로 교체:
```python
if st.button("업그레이드 (₩49,000/월)"):
    # TODO: 결제 API 연동
    st.info("결제 페이지 연동 필요")
```

### 사용자 DB 연동
현재는 딕셔너리 기반 임시 인증. 실제 운영 시 SQLite / PostgreSQL 연동:
```python
DEMO_USERS = {
    "demo@hospital.com": {"pw": hash_password("demo1234"), "plan": "free"},
}
```
